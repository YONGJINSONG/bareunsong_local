- 반지름 6 / 10 / 12px(카드). 그림자는 아주 옅게 한 단계만 쓴다.
- 간격: 카드 안쪽 18px, 목록 줄 높이 40px(기본 밀도), 카드 사이 16px.
- 의미 색(경고·위험·정상)은 포인트 색과 따로 쓰고, 상태는 색과 글자(칩 문구)로 함께 표시한다.

## 3. 글꼴

- **Pretendard Variable**(OFL-1.1)을 프로젝트 안에 포함한다(`docs/design/fonts/PretendardVariable.woff2`, 서비스에서는 정적 파일로 제공). 인터넷이 없어도 보여야 한다.
- 대체 글꼴: Apple SD Gothic Neo, Malgun Gothic.
- 크기: 본문 14px, 보조 12~12.5px, 카드 제목 14.5px/700, 페이지 제목 22px/700, 요약 숫자 22px.
- 숫자가 줄을 맞춰야 하는 곳(표, 수량, 금액, 날짜)은 `tabular-nums`를 쓴다.

## 4. 레이아웃·구성

- **앱 골격**
  - 상단바(56px): 병원명, 검색, 데모 모드 표시, 알림, 밝기 전환, 사용자
  - 왼쪽 메뉴(232px): 대시보드와 7개 묶음(접기·펴기). 하위 항목에 건수 배지를 단다.
  - 본문: 최대 1720px, 좌우 24px
- **반응형**
  - 1480px 이상: 대시보드 4열
  - 1101~1479px: 3열
  - 721~1100px(태블릿): 2열, 메뉴는 64px 아이콘 막대
  - 720px 이하(휴대폰): 1열, 아래쪽 탭 막대(홈·재고·AI·근무·더보기)
- **대시보드 순서**
  1. 요약 숫자 6개: 오늘 근무, 체크리스트, 재고 경고, 30일 내 점검·의무, 승인 대기, AI 사용
  2. 카드: 오늘 할 일, 재고 경고, 점검·의무 일정, 오늘 근무, 공지(2칸), AI 빠른 요청, 발주 진행, 이번 주 일정(2칸), 최근 입출고, 이번 달 지출(원장·실장만)
- **목록 화면**: 위에 도구줄(분류 필터와 상태 필터), 그 아래 표. 표 안에서 현재고 대비 막대와 상태 칩을 보여 준다.
- **AI 입력 화면**
  - 입력창 바로 위에 빨간 "환자 개인정보 입력 금지" 안내를 둔다.
  - 입력 중 개인정보 패턴이 보이면 노란 경고를 띄운다.
  - 등급별 예상 비용을 표시하고, 결과 아래에 "참고용·법률 자문 아님" 고지를 단다.
- **문서 결과**: A4 종이 모양 미리보기(문서 머리줄, 가운데 제목, 서명 줄)를 쓰고, 의료광고 점검 결과 상자를 붙인다.

## 5. 관찰 가능한 시각 품질 기준 (NFR-006·NFR-007 연결)

1. 1440·1024·768·390px 각 너비에서, 라이트·다크 두 테마로 스크린샷을 찍는다. 확인할 것:
   - 가로 스크롤 없음
   - 글자 잘림·겹침 없음
   - 카드 가장자리가 맞음
2. 본문 글자 대비가 4.5:1 이상이다(두 테마 모두 자동 검사).
3. 키보드 포커스가 `--accent` 2px 외곽선으로 보인다.
4. 모든 목록·카드에 빈 상태(안내 문구 + 첫 항목 추가 버튼), 불러오는 중(뼈대 모양), 오류 상태(이유 + 다시 시도)가 있다.
5. 색만으로 상태를 구분하지 않는다. 칩에는 글자가 있다.
6. 대시보드 첫 화면(1440×900)에서 요약 숫자 줄과 첫 줄 카드 4개가 스크롤 없이 보인다.
7. 화면마다 주 행동 버튼(채워진 네이비)은 하나만 둔다.
8. 움직임은 150~300ms의 짧은 전환만 쓰고, `prefers-reduced-motion`을 따른다.
