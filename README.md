# 바른송치과 원내 AX

> **바른송치과의원**에서 쓰려고 [GangJaeYu/NewDentalAX](https://github.com/GangJaeYu/NewDentalAX)(MIT, © 2026 나는타조)를 복제해 고친 판입니다. 원본의 기능·문서·검증 기록은 그대로 두고, 아래만 바꾸거나 더했습니다.
>
> - **바른송치과 디자인** — 포인트 색을 다크 네이비로 바꾸고(케이스북 슬라이드와 통일), 앱 이름을 "바른송치과 원내 AX", 휴대폰 홈 화면 이름을 "바른송 AX"로 했습니다. 첫 설정의 병원 이름 칸에는 "바른송치과의원"이 미리 적혀 있습니다.
> - **출퇴근 기록(새 기능)** — 인사·근무 → 출퇴근 기록, 그리고 대시보드 맨 앞 "출근하기·퇴근하기" 버튼.
>   - **원장님이 정한 병원 와이파이에서만** 찍힙니다(관리: 출퇴근 기록 → 출퇴근 설정에서 대역 지정, "지금 이 기기의 와이파이 추가" 버튼). 서버 PC에서는 늘 찍힙니다.
>   - 근무표 기준으로 **지각·조퇴**를 자동 표시합니다(지각 유예 기본 5분, 승인된 반차는 제외). 퇴근을 깜빡한 날은 "퇴근 누락"으로 보입니다.
>   - 실장 이상은 전 직원 기록·직원별 합계를 보고, **사유를 적어 기록을 고치며**(활동 기록에 남음), 월별 **CSV(엑셀)**로 내려받습니다.
> - 결정 기록: [DECISIONS.md](docs/DECISIONS.md) 맨 아래 D-B00·D-B01
>
> 데모 데이터의 가상 병원 이름(하늘숲치과)은 연습용이라 그대로 두었습니다. 아래부터는 원본 README입니다(체험판 링크는 원본 체험판이라 출퇴근 기능은 없습니다).

## (원본) DentalAX — 치과 원내 AX 웹 서비스 (플러그인 하네스·루프판)

> 코딩을 모르는 치과의사가 **Claude Code + `harness_loop_fullstack_kor` 플러그인**([플러그인 저장소](https://github.com/GangJaeYu/harness_loop_full_korean))으로 만든 원내 업무 웹 서비스입니다.
> 단일 프롬프트판([GangJaeYu/DentalAX](https://github.com/GangJaeYu/DentalAX))과 **같은 요구서**에서 출발했습니다. 이 판은 요구 정의 → 기술·설계 → 태스크 계획 → 검증 하네스 → 구현 루프를 거쳤습니다.

>
> ℹ️ **예시 코드로 공개합니다.** 플러그인으로 만든 결과물을 보여 주는 참고용 저장소입니다. 실제 AI 키 연결과 실제 병원 사용은 확인하지 않았습니다(가상 데이터·데모 응답으로 검증). 쓰실 때는 각자 확인하고 책임지고 써 주세요.

## 빠른 시작 (Windows)

1. **Node.js 24 LTS 설치** — https://nodejs.org
2. **`start.bat`** 더블클릭 → 처음 한 번은 필요한 파일을 자동으로 받습니다(인터넷 필요)
3. 브라우저가 열리면 **http://localhost:8090** 의 "첫 설정"에서 관리자 계정을 만듭니다

직원 PC·태블릿·휴대폰은 검은 창에 나온 `http://192.168.x.x:8090` 주소로 접속합니다. 다른 기기에서 열리지 않으면 Windows 방화벽에서 **개인 네트워크**만 허용합니다.

## 원칙

- **환자 정보를 저장하지 않습니다.** 환자 이름·연락처·주민번호·차트번호·진료 내용을 넣는 칸이 없습니다(DB 스키마를 테스트가 검사).
- AI로 보내는 모든 글은 서버가 먼저 검사해 주민번호·전화번호·카드·계좌번호 등을 **막거나 가립니다**(스트리밍 응답 포함).
- **원내 네트워크 전용**입니다. 인터넷에 공개하지 않습니다.
- API 키는 서버에만 암호화해 저장하고, 브라우저로 보내지 않습니다.

> 이 서비스는 업무 보조 도구이며 법률 자문을 대신하지 않습니다. 개인정보보호법·의료법(의료광고 등)·노무 관련 판단은 전문가와 상의하세요.
